# Network Traffic Investigation

## Overview

A Wireshark-based cybersecurity lab project focused on network traffic analysis, DNS investigation, protocol analysis, and identification of communication patterns.

## Objective

To analyze network traffic captured from an authorized environment and document network communication using packet-level evidence.

## Tools Used

- Wireshark
- Windows
- DNS analysis
- TCP/UDP analysis

## Investigation Areas

- Protocol hierarchy analysis
- Network conversation analysis
- DNS query investigation
- TCP/UDP traffic analysis
- Source and destination communication review
- Packet-level evidence analysis

## Key Findings

- Analyzed 6,715 packets.
- Observed approximately 6 MB of network traffic.
- Reviewed network conversations over approximately 166.85 seconds.
- Investigated DNS queries to multiple service-related domains.
- Compared traffic volume between communicating endpoints.
- Documented observations using evidence-based analysis.

## Disclaimer

The presence of a domain, IP address, port, or protocol in a packet capture does not by itself indicate malicious activity. Security conclusions should be based on multiple sources of evidence and appropriate investigation.
